## 🧩 About

**Destiny 2 overlay Menu** is a curated list of Destiny 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, overlay viewer, loadout switcher
- **Quality-of-Life Helpers** — inventory catalog, shader manager, overlay notes
- **Research Notes** — strike layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Combat Helpers
- overlay Overlay — visualize enemy positions and loot nodes
- Hitbox Viewer — display hitboxes for study
- Replay Notes — record and review strike runs
- Playback Speed — adjust playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Inventory Catalog — browse weapons, armor, shaders, emblems
- Custom Loadout Notes — organize gear and mods
- Shader Manager — preview and organize shaders

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any strike
- Gravity Control — manually adjust gravity in private matches
- Jump Buffer Notes — chain complex maneuvers in the editor

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
